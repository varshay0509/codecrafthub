# CodeCraftHub 📚

**CodeCraftHub** is a beginner-friendly REST API for tracking courses you want to learn. Built with **Python and Flask**, it stores your course list in a local **JSON file**—no database, login, or frontend required.

This project is designed to help first-time API developers understand HTTP methods, routes, JSON requests and responses, validation, status codes, and persistent storage.

## 1. Features

- **Create** a course with a name, description, target date, and status.
- **List** all courses or **retrieve** one course by ID.
- **Update** an existing course's details.
- **Delete** a course.
- Automatically assign an integer **ID** (starting at 1) and a UTC **creation timestamp**.
- Validate required fields, supported statuses, and calendar dates.
- Automatically create `courses.json` if it does not exist.
- Return JSON error messages for invalid requests, missing courses, and storage failures.
- Keep course data between application restarts.

**Supported statuses:** `Not Started`, `In Progress`, `Completed` (case-sensitive).

## 2. Project structure

```text
CodeCraftHub/
├── app.py             # Flask application, API routes, validation, file operations
├── courses.json       # Course data; created automatically if missing
├── requirements.txt   # Python dependency list
└── README.md          # This guide
```

`courses.json` initially contains:

```json
[]
```

Each course eventually looks like this (ID and timestamp are generated by the server):

```json
{
  "id": 1,
  "name": "Python for Data Science",
  "description": "Learn Python for data analysis",
  "target_date": "2026-12-31",
  "status": "Not Started",
  "created_at": "2026-10-15T10:30:00+00:00"
}
```

`created_at` is an example UTC timestamp; yours will be different.

## 3. Prerequisites

- **Python 3.9 or later** installed.
- A terminal (Windows Command Prompt, PowerShell, macOS Terminal, or Linux shell).
- A text editor (for example, VS Code).
- Optional: Postman for sending HTTP requests. The examples below use cURL instead.

Check your Python installation:

```bash
python --version
```

On some macOS/Linux systems, use `python3` in place of `python`.

## 4. Installation: step by step

**Step 1 — Create a project folder** and place `app.py` inside it:

```bash
mkdir CodeCraftHub
cd CodeCraftHub
```

If you already have the project folder, just open a terminal inside it.

**Step 2 — Create a virtual environment** (recommended to isolate project dependencies):

```bash
python -m venv .venv
```

**Step 3 — Activate the environment:**

Windows Command Prompt (CMD):

```cmd
.venv\Scripts\activate.bat
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
source .venv/bin/activate
```

If PowerShell blocks activation, you can use Command Prompt instead, or run the virtual environment's Python executable directly.

**Step 4 — Create `requirements.txt`** with:

```text
Flask>=3.0,<4.0
```

**Step 5 — Install dependencies:**

```bash
python -m pip install -r requirements.txt
```

**Step 6 — Check that `app.py` is present.** You do **not** need to create `courses.json` manually; the app creates it on startup if missing.

## 5. Run the application

From the project folder, with the virtual environment activated:

```bash
python app.py
```

You should see output similar to:

```text
 * Serving Flask app 'app'
 * Debug mode: on
WARNING: This is a development server. Do not use it in a production deployment.
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit
```

Keep this terminal open. In a **second terminal**, visit or request:

```text
http://127.0.0.1:5000/api/courses
```

If no courses have been added, the response is `[]`.

Stop the server with **Ctrl+C** in the terminal where Flask is running.

> **Development only:** `debug=True` automatically reloads code and shows debugging details. Never expose this debugger to the public internet. This JSON-file design is for local learning, not multi-process production use.

## 6. API reference

**Base URL:** `http://127.0.0.1:5000`

| Method | Endpoint | Purpose | Success code |
|---|---|---|---|
| `POST` | `/api/courses` | Create a course | `201 Created` |
| `GET` | `/api/courses` | List all courses | `200 OK` |
| `GET` | `/api/courses/<id>` | Get one course | `200 OK` |
| `PUT` | `/api/courses/<id>` | Replace editable course fields | `200 OK` |
| `DELETE` | `/api/courses/<id>` | Delete a course | `200 OK` |

`<id>` is a positive integer, such as `1`. For example, `/api/courses/1` refers to the course with ID 1.

### POST `/api/courses` — Create a course

Send all four editable fields; **do not send `id` or `created_at`**.

**JSON request body:**

```json
{
  "name": "Python for Data Science",
  "description": "Learn Python for data analysis",
  "target_date": "2026-12-31",
  "status": "Not Started"
}
```

**Windows CMD — copy and paste:**

```cmd
curl.exe -i -X POST "http://127.0.0.1:5000/api/courses" -H "Content-Type: application/json" -d "{\"name\":\"Python for Data Science\",\"description\":\"Learn Python for data analysis\",\"target_date\":\"2026-12-31\",\"status\":\"Not Started\"}"
```

**macOS/Linux/Git Bash — copy and paste:**

```bash
curl -i -X POST 'http://127.0.0.1:5000/api/courses' -H 'Content-Type: application/json' -d '{"name":"Python for Data Science","description":"Learn Python for data analysis","target_date":"2026-12-31","status":"Not Started"}'
```

**Example response — `201 Created`:**

```json
{
  "created_at": "2026-10-15T10:30:00+00:00",
  "description": "Learn Python for data analysis",
  "id": 1,
  "name": "Python for Data Science",
  "status": "Not Started",
  "target_date": "2026-12-31"
}
```

The ID is `1` only if the file starts empty. Your timestamp will reflect the time of creation.

### GET `/api/courses` — List all courses

```bash
curl -i http://127.0.0.1:5000/api/courses
```

**Example response — `200 OK`:**

```json
[
  {
    "id": 1,
    "name": "Python for Data Science",
    "description": "Learn Python for data analysis",
    "target_date": "2026-12-31",
    "status": "Not Started",
    "created_at": "2026-10-15T10:30:00+00:00"
  }
]
```

An empty collection returns `[]` with status `200`.

### GET `/api/courses/1` — Get one course

```bash
curl -i http://127.0.0.1:5000/api/courses/1
```

**Example response — `200 OK`:** The JSON object shown in the POST response above. If ID `1` does not exist, the API returns `404`.

### PUT `/api/courses/1` — Update a course

A PUT request must contain **all four editable fields**, even if only one changes. The server preserves `id` and `created_at`.

**JSON request body:**

```json
{
  "name": "Python for Data Science",
  "description": "Learn Python, NumPy and Pandas",
  "target_date": "2027-01-31",
  "status": "In Progress"
}
```

**Windows CMD:**

```cmd
curl.exe -i -X PUT "http://127.0.0.1:5000/api/courses/1" -H "Content-Type: application/json" -d "{\"name\":\"Python for Data Science\",\"description\":\"Learn Python, NumPy and Pandas\",\"target_date\":\"2027-01-31\",\"status\":\"In Progress\"}"
```

**macOS/Linux/Git Bash:**

```bash
curl -i -X PUT 'http://127.0.0.1:5000/api/courses/1' -H 'Content-Type: application/json' -d '{"name":"Python for Data Science","description":"Learn Python, NumPy and Pandas","target_date":"2027-01-31","status":"In Progress"}'
```

**Example response — `200 OK`:** The API returns the **updated course object** (not merely a success message):

```json
{
  "id": 1,
  "name": "Python for Data Science",
  "description": "Learn Python, NumPy and Pandas",
  "target_date": "2027-01-31",
  "status": "In Progress",
  "created_at": "2026-10-15T10:30:00+00:00"
}
```

### DELETE `/api/courses/1` — Delete a course

```bash
curl -i -X DELETE http://127.0.0.1:5000/api/courses/1
```

**Example response — `200 OK`:**

```json
{
  "message": "Course deleted successfully"
}
```

After deletion, `GET /api/courses/1` returns `404`.

## 7. Testing instructions

Start Flask in one terminal, then run these commands in a second terminal. The following short commands work in CMD, PowerShell (using `curl.exe` instead of `curl`), and macOS/Linux shells (using `curl`).

**Suggested manual test sequence:**

1. **GET all:** `curl -i http://127.0.0.1:5000/api/courses` — expect `200` and a JSON list.
2. **POST:** use the POST example above — expect `201` and a new `id`.
3. **GET one:** `curl -i http://127.0.0.1:5000/api/courses/1` — expect `200` if ID 1 exists.
4. **PUT:** use the PUT example above — expect `200` and updated fields.
5. **DELETE:** `curl -i -X DELETE http://127.0.0.1:5000/api/courses/1` — expect `200`.
6. **GET deleted ID:** request it again — expect `404`.

**Tip:** On Windows, substitute `curl.exe` for `curl` in these short examples. If you already have courses, use the actual ID returned by POST rather than assuming ID 1.

### Negative tests: expected failures

These commands use **Windows CMD** quoting. For macOS/Linux, follow the single-quote style shown in the POST example.

**Missing required field (`name`) — expect `400`:**

```cmd
curl.exe -i -X POST "http://127.0.0.1:5000/api/courses" -H "Content-Type: application/json" -d "{\"description\":\"Learn Python\",\"target_date\":\"2026-12-31\",\"status\":\"Not Started\"}"
```

Example error:

```json
{"error":"Missing required fields: name"}
```

**Invalid status — expect `400`:**

```cmd
curl.exe -i -X POST "http://127.0.0.1:5000/api/courses" -H "Content-Type: application/json" -d "{\"name\":\"Python\",\"description\":\"Learn Python\",\"target_date\":\"2026-12-31\",\"status\":\"Learning\"}"
```

Example error:

```json
{"error":"Invalid status. Use: Not Started, In Progress, or Completed"}
```

**Invalid calendar date — expect `400`:**

```cmd
curl.exe -i -X POST "http://127.0.0.1:5000/api/courses" -H "Content-Type: application/json" -d "{\"name\":\"Python\",\"description\":\"Learn Python\",\"target_date\":\"2026-02-30\",\"status\":\"Not Started\"}"
```

Example error:

```json
{"error":"Invalid target_date. Use YYYY-MM-DD (e.g. 2026-12-31)"}
```

**Course not found — expect `404`:**

```cmd
curl.exe -i http://127.0.0.1:5000/api/courses/999
```

Example error:

```json
{"error":"Course not found"}
```

**Malformed JSON — expect `400`:**

```cmd
curl.exe -i -X POST "http://127.0.0.1:5000/api/courses" -H "Content-Type: application/json" -d "{\"name\":\"Python\",}"
```

The API returns a JSON error indicating that the request body must be a JSON object.

**Other useful tests:** empty strings, `null` values, numeric names, missing `description`/`target_date`/`status`, and PUT/DELETE for nonexistent IDs. Invalid requests should not change `courses.json`.

### Verify persistence

1. Create a course and note its ID.
2. Stop Flask with **Ctrl+C**.
3. Restart with `python app.py`.
4. Call `GET /api/courses/<id>` again.

The course should still be there because it was saved in `courses.json`.

### Verify automatic file creation (optional)

Stop Flask, **back up** your current `courses.json`, and temporarily rename it. Start Flask again: a new `courses.json` containing `[]` should appear. After testing, stop Flask and restore your backup. Do not delete your real data without a backup.

## 8. Troubleshooting

| Problem | Likely cause | What to try |
|---|---|---|
| `python` is not recognized | Python is not installed or not on PATH | Install Python, reopen terminal, try `py --version` on Windows or `python3 --version` on macOS/Linux. |
| `ModuleNotFoundError: No module named 'flask'` | Flask is not installed in the active Python environment | Activate `.venv` and run `python -m pip install -r requirements.txt`. |
| PowerShell says script execution is disabled | PowerShell execution policy blocks activation | Use Command Prompt and `.venv\Scripts\activate.bat`, or run `.venv\Scripts\python.exe app.py`. |
| `Address already in use` / port 5000 busy | Another program is using port 5000 | Stop the other process, or change the port in `app.run(...)` and update the URLs. |
| `curl: (7) Failed to connect` | Flask is not running or the port is wrong | Start `python app.py`; verify the URL and port shown in the terminal. |
| `404 Not Found` | Wrong path or nonexistent course ID | Check `/api/courses` and use an existing ID. |
| `405 Method Not Allowed` | HTTP method does not match the route | Check the endpoint table; e.g. POST is for `/api/courses`, not `/api/courses/1`. |
| `400 Bad Request` | Missing/invalid fields or invalid JSON | Check field names, string values, exact statuses, date format, and `Content-Type`. |
| JSON file read error (`500`) | File is corrupted, unreadable, or contains something other than a JSON list | Back up and inspect `courses.json`; fix it instead of deleting your data. |
| JSON file write error (`500`) | Storage location is not writable or disk is full | Check folder permissions and free disk space. |
| Browser shows `[]` | No courses have been created yet | Send a POST request to add a course. |
| CMD cURL request fails due to quotes | JSON quotes are not escaped | Copy the **Windows CMD** examples exactly; use different quoting on macOS/Linux. |

If Flask displays `* Debugger is active!` or `* Restarting with stat`, that is normal while debug mode is enabled. The debugger PIN is sensitive: do not publish it.

## 9. How the API works (mental model)

```text
Client (browser, cURL, Postman)
          |
          | HTTP request: GET /api/courses
          v
Flask route in app.py
          |
          | Python reads courses.json
          v
Course list (Python list of dictionaries)
          |
          | Flask converts it to JSON
          v
HTTP response: 200 OK + JSON body
```

- **Client:** the program making a request.
- **Endpoint/route:** a URL path paired with an HTTP method.
- **Request body:** JSON data sent with POST and PUT.
- **Response body:** JSON returned by Flask.
- **Status code:** a number indicating success (`200`, `201`) or an error (`400`, `404`, `500`).

## 10. Limitations and next steps

This project intentionally uses a single JSON file. It is suitable for learning and small local experiments, but **not for production deployment** or multiple application processes writing concurrently. IDs are generated from the highest existing ID, so deleting the highest-ID course may allow that ID to be reused later.

Once you are comfortable with the five CRUD operations, try adding a status filter, a PATCH endpoint for updating only the status, or automated tests with Flask's test client.

---

**Happy learning!** CodeCraftHub is a hands-on way to understand how a REST API receives requests, validates input, saves data, and returns useful responses.
